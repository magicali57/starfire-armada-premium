# Starfire Armada — Complete Economy Document

**Status:** Design baseline. Values are provisional until gameplay balancing.

**Approved structural decision:** remove the Weapon action from Ship Detail. Arsenal is the single place for weapon management and upgrades.

## Launch Economy Summary

- Main resources: Credits, Crystals, Energy, Player XP
- Upgrade materials: Ship Parts, Ship Shards, Companion Data, Companion Shards, Module Parts, Weapon Parts
- Collections: Ships, Companions, Modules, Arsenal Weapons, optional Skins
- Core power-ups: Shield, Damage Boost, Rapid Fire, Health Repair, Missile Barrage
- Core containers: Basic Chest, Rare Chest, Epic Chest
